Powerful Capabilities

Built for Precision, Security & Reliability

Everything needed for university examinations, semester quizzes, and practical code skill assessments.

Dynamic Countdown Timer

Automated countdown with visual warning triggers when 2 minutes remain. Automatically freezes and submits upon expiration.

Interactive Question Palette

Real-time visual indicators color-code every question: Current (Blue), Answered (Green), Marked for Review (Orange), and Unanswered (Gray).

Accidental Exit & Tab Monitor

Includes window unload protection (`beforeunload`) and monitors tab-switching violations during candidate testing sessions.

Automated Grading Engine

Calculates percentages, total scores, correct vs incorrect counts, academic letter grades, and generates immediate reviews with explanations.

Comprehensive Question Bank

Manage categorized questions across HTML5, CSS3, JavaScript ES6+, Computer Fundamentals, and Web Systems with full CRUD support.

Role-Based Dashboards

Tailored workflows for students taking exams and administrators reviewing analytics, managing rosters, and exporting reports.
